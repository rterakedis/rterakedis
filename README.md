# Robert Terakedis

I build the systems that connect the other systems: AI pipelines, enterprise integrations, workflow automation. If there's a manual process somewhere that people repeat all week, that's the problem I want to solve.

I'm a Principal Solutions Architect, and I work remotely. Lately that's Azure and LLM work, mostly in Python, and I'm picking up Go. I started in datacenters, then spent about a decade in Apple platforms and enterprise device management, so I still care a lot about what happens after something ships.

I hold CIPP/E and CIPM certifications, which means I've been doing privacy-by-design thinking before it became a tagline. One US patent ([US 10,284,554](https://patents.google.com/patent/US10284554B2)).
